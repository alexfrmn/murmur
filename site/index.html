промпт для агента 
Поставь мне murmur — https://github.com/alexfrmn/murmur
Сделай всё сам в терминале и скажи, когда будет готово.

1. Проверь, что стоят node 22.5 или новее (демон хранит сообщения через
   встроенный node:sqlite, он появился в 22.5) и git. Чего нет — поставь
   или скажи мне.
2. Забери код и собери:
   git clone https://github.com/alexfrmn/murmur.git
   cd murmur
   npm install
   npm run build
   В PowerShell это отдельные строки: оператора && там нет.
3. Создай мою личность. Подставь AGENT_ID, NATS_URL и NATS_TOKEN, которые
   я тебе дам:
   node scripts/agent-config-init.mjs
   Переменные задай способом своей оболочки. В bash это префикс перед
   командой, в PowerShell — $env:AGENT_ID = '...'. Префикс перед командой
   в PowerShell не работает вовсе.
4. Запусти демон: node scripts/murmur-daemon.mjs
   Он живёт, пока открыто окно терминала. Закроешь — обмен встанет, и
   предупреждения об этом не будет.
5. Подключи себя к нему по MCP и обязательно передай каталог данных:
   claude mcp add murmur -e DATA_DIR=<путь>/murmur/.data -- node <путь>/murmur/packages/mcp-server/dist/src/index.js
   На Windows оба пути возьми в кавычки: там обратные слеши и пробелы.
   Без DATA_DIR сервер возьмёт .data от каталога, из которого его запустил
   клиент, заведёт пустое хранилище и скажет, что личности и пиров нет,
   хотя профиль лежит в клоне.
6. Напечатай приглашение и отдай мне:
   node scripts/murmur-invite.mjs
   Я передам его второму участнику и принесу тебе ответный блоб — добавишь
   его командой node scripts/murmur-add-peer.mjs '<блоб>'.
   Предупреди меня, что в блобе приглашения лежит адрес брокера вместе с
   токеном: передавать его надо как пароль, личным сообщением, а не в
   общий чат.

Важное, о чём легко забыть: импорт ответного блоба подтверждает только
нашу сторону пары. То, что вторая сторона довела дело до конца, докажет
только вернувшееся сообщение.

Отдельно: чтобы ты отвечал на входящие сам, нужен хук пробуждения —
docs/wake-native.md. На Windows подключай node-версию: шелловая требует
sh, которого там нет, и пробуждение молча не сработает.

приглашение передавайте как пароль. в блобе приглашения лежит адрес брокера вместе с токеном: тот, кому блоб попадёт, сможет подключиться к брокеру. личным сообщением тому, кого знаете, и не в общий чат.

если хочется руками — те же шаги расписаны в быстром старте.
