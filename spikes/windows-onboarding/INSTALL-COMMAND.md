# Установка службы Windows из готового runtime

Нужны Node.js 22.13.0 или новее, распакованный runtime и соответствующий ему
`runtime/bin/murmur-svc.exe`. Переносимый ZIP движка не содержит этот Windows-бинарник.
Компиляция Go, npm и Git на машине получателя готового комплекта не нужны.

Откройте PowerShell от имени администратора под тем же пользователем, который владеет
профилем. Сначала создайте личность через общие CLI init/join из Quick Start.
Укажите реальные абсолютные пути; установщик не создаёт и не меняет ключи.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Murmur.ps1 -AgentId alice -RuntimeRoot 'C:\Murmur\runtime' -DataDir 'C:\Users\you\AppData\Local\Murmur' -ServiceName MurmurDaemon
```

`Bypass` действует только в этом процессе для явно выбранного локального скрипта;
машинная политика выполнения не меняется. Подпись дистрибутива пока отсутствует.
Просмотрите файл и используйте комплект из официального релиза. ZIP с названием
Source code на GitHub не является готовым runtime.

Скрипт проверяет права, пути, Node через штатную команду CLI version, наличие helper и
занятое имя службы/задачи до изменений. Статус должен подтвердить уже существующую
личность. Затем общий CLI устанавливает службу и снимает новый статус. Нужны ожидаемый agentId,
состояние running, PID демона и наблюдаемый открытый файл SQLite.

Повторная установка под занятым именем отказывается до изменений. Helper
повторно проверяет владение при мутации; общей атомарной блокировки между preflight
и установкой нет. Проверка задачи Планировщика охватывает только указанное имя:
она не доказывает отсутствия другого вручную запущенного демона на том же профиле.

Ноль означает подтверждённую локальную службу. Он не доказывает доступность пира,
ответ AI или работу после перезагрузки. При поздней ошибке предыдущие шаги могли
завершиться; автоматического удаления приватных данных нет. Скрипт не инициализирует профиль и не выводит ключи или токен.

Значок, автозапуск, клиентские конфиги и приглашения этот скрипт не меняет. Продолжите
[Quick Start](../../README.md#quick-start), передавая те же `--data-dir` и
`--service-name MurmurDaemon` каждой команде, включая clients configure и doctor.
Передачу invite выполняйте через доверенный приватный канал; reply содержит публичные ключи.

```powershell
$Cli = 'C:\Murmur\runtime\packages\setup\bin\murmur.mjs'
$Profile = 'C:\Users\you\AppData\Local\Murmur'
node $Cli status --data-dir $Profile --service-name MurmurDaemon --json
node $Cli service stop --data-dir $Profile --service-name MurmurDaemon --json
node $Cli service uninstall --data-dir $Profile --service-name MurmurDaemon --json
```

Stop и uninstall требуют повышения прав. Uninstall сохраняет профиль и журналы.
Изменение окружения ограничено процессом установщика и восстанавливается при выходе.
Скрипт не останавливает все процессы значка по имени и не регистрирует непроверенный
автозапуск. Клиент требуется явно перезагрузить после настройки MCP.
