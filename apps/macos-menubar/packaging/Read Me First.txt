Murmur for Mac

1. Move Murmur to Applications.
2. Open Murmur from Applications.
3. Choose I have an invitation and paste the MURMUR: line sent by your colleague (a file is also accepted).
4. Use Show and copy Reply and send that line back to the person who invited you.
5. Click Start Murmur on this Mac, then Connect your AI assistants and restart the assistant.
   After exchanging the reply, check the connection.

If you have your own server, choose Create a profile for my server and enter its address.
Already configured? Choose your existing profile folder instead.

Click the menu bar icon to open or hide the window; right-click for quick actions.
If the icon is hidden, open Murmur again from Applications or press Control–Option–Command–M.
Before choosing a profile, the quick menu contains only Choose profile folder and Quit.

The app includes the Murmur engine. Opening it requires no Terminal commands or code build.
Profile creation and the explicit Start button use the bundled Murmur CLI behind the window.
The app creates a private profile folder for you. It does not silently start a service.
Connect your AI assistants configures Claude Code, Claude Desktop or the Codex CLI; restart
the assistant afterwards. Claude Desktop and Claude Code (the Code tab in Claude Desktop is
Claude Code) are connected separately. Other clients follow the CLI onboarding instructions:
https://github.com/alexfrmn/murmur/blob/main/docs/setup-onboarding.md
A created profile or running service does not by itself prove pairing or agent delivery.

A compatible Node.js installation is required. If it is missing or too old, Murmur
shows a link to the official Node.js website and a Try again button.
English is the default app language. Choose Settings → Language → Русский to switch to Russian.
macOS dialogs use your system language.

First opening

This build has an ad-hoc signature, without Developer ID or Apple notarization.
macOS shows a warning with no Open button. Checked with Murmur 2.12.0 on macOS 26.6:
open the installed app → Done (not Move to Trash) → System Settings → Privacy & Security →
Security section → Open Anyway → confirm with your password or Touch ID → open Murmur
again → Open. Apple documents that route here: https://support.apple.com/102445

On some systems Finder's right-click → Open on the installed app also works after Done;
on macOS 26 with this image it no longer offered to run the app.
Button names depend on your macOS version and language.
A DMG does not remove macOS security warnings. Keep Gatekeeper enabled.
