Murmur for Mac

1. Move Murmur to Applications.
2. Open Murmur from Applications.
3. In the Murmur window, choose your existing profile folder.

Click the menu bar icon to open or hide the window; right-click for quick actions.
If the icon is hidden, open Murmur again from Applications or press Control–Option–Command–M.
Before choosing a profile, the quick menu contains only Choose profile folder and Quit.

The app includes the Murmur engine. Opening it requires no Terminal commands or code build.
Creating a profile, connecting your agent client and installing its background service
still use Murmur CLI. The app does not create a profile or install a service automatically.

A compatible Node.js installation is required. If it is missing or too old, Murmur
shows a link to the official Node.js website and a Try again button.
English is the default app language. Choose Settings → Language → Русский to switch to Russian.
macOS dialogs use your system language.

First opening

This build has an ad-hoc signature, without Developer ID or Apple notarization.
macOS may show a warning with no Open button. On macOS 26.6.2 with a Russian interface,
the tested path was: open the installed app → Done (Готово) → right-click Murmur →
Open (Открыть). No second dialog appeared in that test; no password or Touch ID was requested.

Other macOS versions may require opening System Settings → Privacy & Security and
allowing this specific app. Apple documents that route here:
https://support.apple.com/102445

Button names and the available route depend on your macOS version and language.
A DMG does not remove macOS security warnings. Keep Gatekeeper enabled.
