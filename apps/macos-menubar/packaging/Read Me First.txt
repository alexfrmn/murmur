Murmur для Mac — проверочная сборка

1. Перетащите Murmur в Applications («Программы»).
2. Откройте Murmur из папки «Программы».
3. Значок Murmur появится в строке меню. Выберите папку профиля в его меню.

Приложение содержит движок Murmur. Для открытия приложения Terminal и сборка кода не нужны.
Создание профиля, подключение клиента и установка службы пока выполняются общим Murmur CLI.
Требуется установленный Node.js подходящей для движка версии. Если версия не найдена,
Murmur покажет, как перейти на официальный сайт Node.js и повторить проверку.
Приложение не создаёт профиль и не устанавливает службу автоматически.

Первое открытие и macOS

Эта проверочная сборка не имеет подписи Developer ID и нотариального заверения Apple.
macOS может показать предупреждение без кнопки «Открыть».
На macOS 26.6.2 в проверке скачанного DMG сработал путь: обычное открытие → «Готово» →
правый щелчок по установленному Murmur → «Открыть». Второго диалога не наблюдалось.
Официальный путь Apple: попробуйте открыть приложение, затем откройте
«Системные настройки» → «Конфиденциальность и безопасность» и разрешите открытие
именно Murmur. macOS может запросить пароль или Touch ID и повторное подтверждение.
Точное название кнопки зависит от версии macOS и языка системы.
https://support.apple.com/102445

Образ DMG не отменяет предупреждения macOS. Не отключайте Gatekeeper целиком.
Это предварительная сборка для проверки установки, а не стабильный выпуск.
